# 🍔 Fast Food

A modern fast-food ordering platform with secure authentication, menu management, and seamless order processing.

## ✨ Features

- 🔐 JWT Authentication
- 🍕 Food Menu Management
- 🛒 Shopping Cart
- 📦 Order Processing
- 📤 Image Uploads with Multer
- 🌐 RESTful API
- 🚀 Fast and Responsive Design

## 🛠️ Tech Stack

### Backend

- Node.js
- Express.js
- JSON Web Token (JWT)
- Multer
- CORS

### Database

- MongoDB (optional)

## 🚀 Installation

```bash
git clone https://github.com/suhaybEromi/fast-food.git
cd fast-food
npm install
```

## ▶️ Run the Project

```bash
npm start
```

or

```bash
node app.js
```
